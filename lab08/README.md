# Лабораторна робота №8 — GRASP

## Передача роботи напарнику

Реалізація — Java, варіант 5: автопрокат. Код розташований у `src/`, без Maven/Gradle. Основний сценарій — оформлення оренди через консоль.

## Що вже зроблено

- **Завдання 1 — аудит і ADR:** у [`analysis.md`](analysis.md) описані проблеми legacy-коду, альтернативи дизайну, прийняті рішення та компроміси. Файл поки в корені `lab08`; методичка вказує для ADR теку `docs/adr/`.
- **Завдання 2 — Information Expert + Creator:** у `VehicleRentalSystem` містяться доменні сутності з приватним незмінним станом, перевірками даних і бізнес-розрахунками. Договір створюється фабрикою `RentalAgreement.create(...)`.
- **Завдання 3 — CLI + Controller + Indirection + Pure Fabrication:** інтерактивне консольне оформлення оренди; DTO запиту; контролер отримує авто й зберігає договір через інтерфейси. Каталог і репозиторій мають in-memory реалізації.

## Збірка та запуск

З кореня каталогу `lab08`:

```bash
javac -Xlint:all -d /tmp/lab08-classes src/*.java
java -cp /tmp/lab08-classes lab08.src.Main
```

У меню введіть `1`, щоб оформити оренду, або `0`, щоб завершити програму. Для сценарію введіть ID клієнта, ім’я, стаж, телефон, ID авто, кількість днів і `BASIC` або `FULL`.

Поточний каталог містить три демонстраційні авто: Corolla (Economy, 1500 грн/день), Camry (Business, 2200 грн/день), RAV4 (SUV, 1800 грн/день). Приклад: RAV4, 5 днів, Full, стаж 4 роки дає оренду 10 800 грн, страховку 2 500 грн, заставу 5 000 грн і загалом 13 300 грн.

## Обмеження та наступні кроки

- In-memory каталог і репозиторій демонструють абстракції, але дані втрачаються після завершення процесу. Постійної бази й SMS немає.
- Немає автоматизованих тестів; перевірка на цей момент — компіляція та ручний запуск сценарію.
- У методичці наступні етапи: **завдання 4** — поліморфізм і Protected Variations; **завдання 5** — розрахунок CBO та LCOM4 і порівняння метрик; **завдання 6** — крос-рев’ю та підготовка до захисту.
- Перед подальшою роботою звіряйте описи рішень у `analysis.md` із фактичним кодом і оновлюйте документ разом зі змінами.
